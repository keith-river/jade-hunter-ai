アプリ概要

新潟県糸魚川市はヒスイの産地として世界的に有名ですが、一般人が自力で発見できる確率は極めて低い。 このアプリは 天気・波浪データ×AI画像識別×ゲーム学習 を組み合わせ、 限られた訪問チャンスを最大活用するための意思決定を支援します。

4大モジュール
🌊 天気・波浪予測 Open-Meteo API
前日波高3m超 → ヒスイが浜に打ち上げられやすい条件。候補日をスコアリングしてカレンダー表示。
📍 スポット推薦 位置情報DB
親不知海岸・小滝川礫層・姫川河口など実績エリアを波浪スコアと合算してランキング。
🔍 AI画像識別 Claude Vision API
撮影した石の写真をAIが硬度・透光性・結晶構造から分析。「ヒスイ度スコア」と根拠説明を返す。
🎮 採集シミュレーション 時間圧縮ゲーム
実際の発見確率を再現した時間圧縮ゲーム。有限チャンスの中で最適な意思決定スキルを鍛える。

# anthropic Vision APIでヒスイ画像識別 import anthropic, base64 def identify_jade(image_path: str) -> dict: client = anthropic.Anthropic() with open(image_path, "rb") as f: img_b64 = base64.b64encode(f.read()).decode() prompt = """この石の画像を分析してください。 判定基準: - 硬度（鉱物学的特性） - 比重（ズッシリ感） - 光沢（ロウ状・繊維状） - 色・透明度 - 結晶構造 以下の形式でJSONのみ返してください: {"jade_score": 0-100, "verdict": "判定結果", "features": ["特徴1","特徴2"], "similar_stones": ["類似石名"], "advice": "採集アドバイス"}""" msg = client.messages.create( model="claude-opus-4-5", max_tokens=512, messages=[{"role": "user", "content": [ {"type": "image", "source": { "type": "base64", "media_type": "image/jpeg", "data": img_b64}}, {"type": "text", "text": prompt} ]}] ) return json.loads(msg.content[0].text)

02
ヒスイ期待スコア計算ロジック
function jadeScore(todayWave, prevWave) { // 前日荒天（波高3m超）がキー条件 const prevFactor = Math.min(prevWave / 3.0, 1.0) * 0.6; // 当日は穏やか → 採集しやすい const calmFactor = (1 - Math.min(todayWave / 2.0, 1)) * 0.4; return Math.round((prevFactor + calmFactor) * 100); } // 例: 前日4.2m → 当日0.8m → スコア88pt 🎯
03
ゲームロジック（確率エンジン）
function calcJadeProb(jadeScore) { // スコアに応じて発見確率を変動 // 平均1/200 → スコア100で約12%まで上昇 const basePct = 0.005; // 0.5% const boost = jadeScore / 100 * 0.115; return basePct + boost; } function searchStone(jadeScore) { const prob = calcJadeProb(jadeScore); return Math.random() < prob; // true = ヒスイ！ }
